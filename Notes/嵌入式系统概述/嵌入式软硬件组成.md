# 嵌入式软硬件组成

> 学习笔记 · 嵌入式系统的硬件与软件构成
> 记录时间：2026-02-14

## 一、总体框架

嵌入式系统是一个**软硬件协同**的整体：硬件提供运行的物质基础，软件赋予其功能与智能。二者按层次组织，自底向上逐层抽象。

```
╔══════════════════════════════════════════════════════════════════════╗
║                          嵌入式系统                                  ║
╠═══════════════════════════════╤══════════════════════════════════════╣
║          硬 件 层              ║            软 件 层                  ║
║  ┌─────────────────────────┐  ║  ┌────────────────────────────────┐  ║
║  │ ① 嵌入式处理器           │  ║  │ ⑤ 应用软件（业务逻辑）          │  ║
║  │   MCU / MPU / DSP / SoC  │  ║  │   算法、界面、通信协议、控制逻辑 │  ║
║  ├─────────────────────────┤  ║  ├────────────────────────────────┤  ║
║  │ ② 存储器                 │  ║  │ ④ 中间件 / 组件库               │  ║
║  │   Flash / SRAM / DDR /   │  ║  │   文件系统、TCP-IP、GUI、DB     │  ║
║  │   EEPROM / eMMC          │  ║  ├────────────────────────────────┤  ║
║  ├─────────────────────────┤  ║  │ ③ 操作系统（可选）              │  ║
║  │ ③ 外设与接口             │  ║  │   裸机 / RTOS / 嵌入式 Linux     │  ║
║  │   GPIO/UART/SPI/I2C/ADC  │  ║  │   任务调度、内存管理、IPC        │  ║
║  │   /PWM/CAN/USB/ETH/无线  │  ║  ├────────────────────────────────┤  ║
║  ├─────────────────────────┤  ║  │ ② 设备驱动 / HAL / BSP          │  ║
║  │ ④ 电源·时钟·复位·看门狗  │  ║  │   寄存器操作、硬件抽象           │  ║
║  ├─────────────────────────┤  ║  ├────────────────────────────────┤  ║
║  │ ⑤ 人机交互器件           │  ║  │ ① 启动代码 / Bootloader         │  ║
║  │   按键/屏/触摸/指示灯     │  ║  │   向量表、时钟初始化、镜像加载    │  ║
║  └─────────────────────────┘  ║  └────────────────────────────────┘  ║
╚═══════════════════════════════╧══════════════════════════════════════╝
        硬件是"身体"                    软件是"灵魂与思想"
```

> 记住一句话：**硬件搭舞台，软件演节目**。分界线是"寄存器"——软件通过读写寄存器控制硬件。

## 二、硬件组成

### 1. 嵌入式处理器（核心）

| 类型 | 说明 | 代表 |
| --- | --- | --- |
| MCU | 单芯片集成 CPU + Flash + RAM + 外设 | STM32、ESP32、GD32 |
| MPU | 需外接 DDR，跑 Linux | i.MX6ULL、RK3568 |
| DSP | 硬件乘加，擅长信号处理 | TI C2000、ADI SHARC |
| FPGA / SoC | 逻辑可编程、软硬协同 | Zynq、Cyclone |

处理器内部包含：运算器 ALU、控制器、寄存器组、流水线、中断控制器（NVIC）、调试接口（SWD/JTAG）。

### 2. 存储器

| 类型 | 掉电 | 速度 | 用途 |
| --- | --- | --- | --- |
| 片内 Flash | 不丢失 | 中 | 存放程序代码、常量表 |
| SRAM | 丢失 | 最快 | 运行数据、堆栈、缓存 |
| ROM / OTP | 不丢失 | 快 | 启动代码、密钥 |
| EEPROM | 不丢失 | 慢 | 配置参数、校准值 |
| 外扩 DDR/SDRAM | 丢失 | 快 | Linux 运行内存 |
| eMMC / NAND / SD | 不丢失 | 中 | 文件系统、固件、日志 |

> 关键概念：**冯·诺依曼结构**（程序与数据同一存储空间）vs **哈佛结构**（指令与数据分开总线，多数 MCU 采用）。

### 3. 外设与接口

**数字通信接口**

| 接口           | 线数                  | 速率               | 特点                             | 典型用途          |
| ------------ | ------------------- | ---------------- | ------------------------------ | ------------- |
| UART         | 2（TX/RX）            | 9600 bps～数 Mbps  | 异步、点对点、简单                      | 调试串口、模块通信     |
| SPI          | 4（SCK/MOSI/MISO/CS） | 数 MHz～数十 MHz     | 同步、全双工、多从机靠片选                  | Flash、屏、ADC   |
| I²C          | 2（SCL/SDA）          | 100 k～3.4 Mbps   | 半双工、地址寻址、需上拉                   | 传感器、EEPROM    |
| CAN / CAN-FD | 2（差分）               | 1 Mbps / 5+ Mbps | 抗干扰、多主、带仲裁                     | 汽车、工业现场       |
| USB          | 2/4                 | 12/480 Mbps+     | 热插拔、可供电                        | 设备、下载、摄像头     |
| 以太网          | 4+（RMII）            | 10/100/1000 Mbps | 需外接 PHY                        | 网关、IPC        |
| 1-Wire       | 1                   | 低                | 单线供电+通信                        | 温度传感器 DS18B20 |
| 无线           | —                   | —                | Wi-Fi/BT/Zigbee/LoRa/NB-IoT/4G | IoT 联网        |

**模拟与其他接口**

| 外设 | 作用 |
| --- | --- |
| ADC | 模拟量 → 数字量（分辨率 12/16 bit，看采样率与参考电压） |
| DAC | 数字量 → 模拟量（波形输出、音量控制） |
| 比较器 / OPAMP | 阈值判断、信号放大 |
| PWM | 调光、调速、舵机、DAC 替代 |
| 定时器 TIM | 定时、计数、输入捕获、编码器接口 |
| DMA | 外设与内存间自动搬数据，不占 CPU |
| RTC | 实时时钟，可掉电走时并定时唤醒 |
| 看门狗 WDT | 程序跑飞时强制复位 |

**人机交互器件**

- 输入：独立按键、矩阵键盘、旋转编码器、触摸屏、麦克风、各类传感器。
- 输出：LED、数码管、LCD/OLED 屏、蜂鸣器、扬声器、继电器、电机驱动。

### 4. 电源、时钟、复位（系统"生命保障"）

| 模块   | 要点                                               |
| ---- | ------------------------------------------------ |
| 电源管理 | LDO / DCDC（效率高、纹波大）、电池充放电管理、多电压域（3.3V/1.8V/1.2V） |
| 时钟   | 内部 RC（HSI/LSI，启动快精度低）+ 外部晶振（HSE/LSE，精度高）+ PLL 倍频 |
| 复位   | 上电复位 POR、掉电复位 PDR、外部按键复位、看门狗复位、软件复位              |
| 低功耗  | Sleep / Stop / Standby 模式，唤醒源（中断、RTC、外部引脚）       |
| 保护   | TVS、ESD 防护、去耦电容、滤波、反接保护                          |

### 5. 硬件设计要点

- **原理图**：电源树、时钟、复位、启动配置引脚（Boot0 等）、调试口引出。
- **PCB**：地平面完整、晶振靠近芯片、去耦电容紧贴引脚、模拟与数字分区、差分对等长。
- **接口保护**：外部接口加 ESD 与限流，防止现场损坏。
- **可测试性**：留测试点、串口调试口、指示灯，方便定位问题。
- **量产考虑**：封装焊接难度、BOM 成本、替代料、烧录工装（SWD 排针/测试点）。

## 三、软件组成

### 1. 启动代码 / Bootloader（最底层）

| 阶段     | 内容                               |
| ------ | -------------------------------- |
| 上电取向量表 | 从 Flash 固定地址取初始 SP 与复位向量         |
| 系统初始化  | 配置时钟/RCC、看门狗、外部存储器控制器            |
| 段初始化   | `.data` 从 Flash 拷到 RAM、`.bss` 清零 |
| 跳转     | 调用 `main()` 或加载应用镜像              |

- **MCU**：BootROM（出厂固化）+ 用户 Bootloader（可用 IAP/OTA 升级）。
- **MPU/Linux**：BootROM → SPL → U-Boot → 内核 → 根文件系统。

### 2. 设备驱动 / HAL / BSP

- **设备驱动**：直接读写寄存器，实现某外设的收发/控制逻辑。
- **HAL（硬件抽象层）**：把寄存器操作封装成 `HAL_GPIO_WritePin()` 之类的函数，屏蔽型号差异。
- **BSP（板级支持包）**：某块具体开发板的驱动集合 + 配置（引脚定义、时钟树、外设实例）。

> 分层价值：换芯片时只需改驱动/BSP，上层应用几乎不动。

### 3. 操作系统（可选）

| 形态 | 说明 | 适用 |
| --- | --- | --- |
| 裸机（前后台） | `main` 大循环 + 中断处理，无调度 | 单任务、逻辑简单、资源极小 |
| 时间片轮询 | 主循环里轮流调用各任务函数 | 中等复杂度、非严格实时 |
| RTOS | 抢占式调度、任务/信号量/队列 | 多任务、强实时 |
| 嵌入式 Linux | 虚拟内存、进程、完整网络与文件系统 | 复杂应用、算力充裕 |

**RTOS 提供的核心能力**

- 任务（线程）与优先级调度；
- 任务间通信：信号量、互斥量、消息队列、事件标志；
- 时间管理：延时、软件定时器、时间片；
- 内存管理：静态分配、内存池（避免碎片）；
- 中断管理与临界区保护。

**主流选择**：FreeRTOS、RT-Thread、μC/OS-III、Zephyr、VxWorks/QNX（商业）。

### 4. 中间件 / 组件库

| 组件 | 常见实现 |
| --- | --- |
| 文件系统 | FATFS、LittleFS、SPIFFS、ext4/YAFFS2、JFFS2 |
| 网络协议栈 | LwIP、FreeRTOS-TCP、Linux 协议栈；MQTT/CoAP/HTTP |
| GUI | LVGL、emWin、TouchGFX、Qt for Embedded |
| 数据库 | SQLite、FlashDB |
| 加解密 | mbedTLS、wolfSSL、硬件加密引擎驱动 |
| 日志/Shell | SEGGER RTT、EasyLogger、FinSH、letter shell |

### 5. 应用软件

- 业务逻辑：采集 → 处理 → 决策 → 输出。
- 典型模块：状态机、控制算法（PID、滤波、FOC）、数据上报、参数管理、固件升级。
- 质量要求：可读性、可测试性、异常处理、看门狗喂狗策略、日志可追溯。

### 6. 支撑软件（开发工具链）

| 类别 | 工具举例 |
| --- | --- |
| 编辑器/IDE | VS Code、Keil MDK、IAR EWARM、STM32CubeIDE、CLion |
| 编译器 | arm-none-eabi-gcc、clang、IAR 编译器 |
| 构建系统 | Make、CMake、Ninja、PlatformIO、Kconfig |
| 调试 | GDB + OpenOCD、J-Link、ST-Link、DAPLink、逻辑分析仪 |
| 仿真/建模 | QEMU、Proteus、MATLAB/Simulink |
| 版本管理 | Git、SVN |
| 测试/CI | Unity/Ceedling、pytest、Jenkins/GitLab CI、静态分析（Cppcheck、Coverity） |

## 四、软硬件如何协同

### 1. 接口边界

```
   应用软件           →  调用  →   中间件/OS API
        ↓
   OS / 驱动           →  读写  →   外设寄存器（内存映射地址）
        ↓
   硬件外设             →  驱动  →   引脚电平 / 总线时序 / 模拟信号
        ↓
   物理世界（传感器、执行器、通信对端）
```

- **内存映射 I/O**：每个外设有一组寄存器地址，软件读写即控制硬件。
- **中断**：硬件事件（按键、串口收数、定时到）打断 CPU，执行 ISR。
- **DMA**：大数据搬运不占 CPU，提高吞吐与实时性。

### 2. 配置外设的标准三步

1. **打开外设时钟**（RCC 使能，最常被遗忘的一步）；
2. **配置引脚复用与电气属性**（AF 功能、上下拉、速度）；
3. **配置外设参数并使能**（波特率/模式/中断/DMA → 使能位）。

### 3. 中断服务程序（ISR）编写原则

- **尽量短**：只做必要动作（读数、置标志、发信号量），耗时处理放到任务里。
- **不阻塞**：禁止在 ISR 中长时间延时或等待信号量。
- **清标志**：处理完必须清除中断标志，否则会重复进入。
- **共享数据保护**：主循环与 ISR 共享的变量用 `volatile` 并注意原子性。
- **优先级设计**：实时性最高的给最高优先级，避免优先级反转（必要时用互斥量优先级继承）。

### 4. 软硬件协同设计流程

```
需求 → 软硬件功能划分（哪些用硬件加速、哪些用软件实现）
     → 硬件设计（原理图/PCB）+ 软件设计（架构/接口定义）
     → 联调（先跑通时钟与串口，再逐个外设）
     → 性能与功耗优化 → 测试与量产
```

> 经典权衡：**用硬件换速度**（FPGA/专用外设）还是**用软件换成本**（通用 MCU + 算法）。

## 五、典型系统配置举例

### 例 1：极简数据采集节点（裸机）

- 硬件：STM32F103 + 温湿度传感器（I²C）+ 段码屏 + 电池。
- 软件：Bootloader + HAL + 主循环（读传感器 → 刷新显示 → 睡眠）+ RTC 定时唤醒。

### 例 2：联网智能设备（RTOS）

- 硬件：ESP32（内置 Wi-Fi/BT）+ 传感器 + 触摸按键 + LED 指示。
- 软件：Bootloader + 驱动 + FreeRTOS（采集任务 / 通信任务 / UI 任务）+ LwIP + MQTT + OTA。

### 例 3：工业 HMI / 网关（嵌入式 Linux）

- 硬件：i.MX6ULL / RK3568 + DDR + eMMC + 触摸屏 + 以太网 + CAN。
- 软件：U-Boot → Linux 内核（设备树）→ 根文件系统 + Qt/LVGL 界面 + 协议栈 + 数据库。

### 三种形态对比

| 配置 | 硬件规模 | 软件栈 | 特点 |
| --- | --- | --- | --- |
| 裸机 | 小 | 驱动 + 主循环 | 简单、省成本、启动快 |
| RTOS | 中 | 驱动 + RTOS + 中间件 | 实时、多任务、功耗可控 |
| Linux | 大 | Bootloader + 内核 + 中间件 + 应用 | 功能强、开发快、资源高 |

## 六、常见问题与排查思路

| 现象 | 可能原因 | 排查方向 |
| --- | --- | --- |
| 外设完全不工作 | 时钟未使能、引脚复用错、外设未使能 | 查 RCC、AF 配置、使能位 |
| 串口乱码 | 波特率不匹配、时钟源频率错、电平不兼容 | 示波器测波形周期 |
| 程序跑飞 / 死机 | 栈溢出、野指针、中断未清标志、电源不稳 | 看门狗 + 栈水位检查 + HardFault 分析 |
| 采不到数据 | 上拉电阻缺失、地址错、时序不满足 | 逻辑分析仪抓总线 |
| ADC 数值跳动大 | 参考电压不稳、地线干扰、未加滤波 | 加去耦、均值/中值滤波 |
| Wi-Fi/通信断连 | 电源电流不足、天线布局差、任务阻塞 | 加大电容、测峰值电流 |
| 升级后变砖 | 无回滚机制、写 Flash 中断电 | 双分区 + 校验 + 看门狗回滚 |

**分层定位法**：物理层（供电/焊接）→ 电气层（电平/时序）→ 寄存器层（配置值）→ 驱动层（API 调用）→ 应用层（逻辑）。

## 八、小结

- 嵌入式系统 = **硬件层（处理器 + 存储器 + 外设接口 + 电源时钟复位 + 交互器件）** + **软件层（启动代码 + 驱动/HAL/BSP + OS + 中间件 + 应用 + 工具链）**。
- 软硬件以**寄存器**为界，通过**中断**与 **DMA** 高效协同。
- 软件栈可简可繁：**裸机够用就不上 RTOS，RTOS 够用就不上 Linux**，一切以需求与成本为准。
- 调试的核心方法是**分层定位**：从供电与时钟查起，再查寄存器配置，最后查应用逻辑。
