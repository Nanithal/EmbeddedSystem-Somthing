# 嵌入式芯片

> 学习笔记 · 嵌入式处理器与芯片知识
> 记录时间：2026-02-14

---

## 一、什么是嵌入式芯片

**嵌入式芯片**是指专门用于嵌入式系统的集成电路，通常在一颗（或少数几颗）芯片上集成处理器核心、存储器、外设接口、时钟与电源管理等功能，作为嵌入式设备的大脑。

一句话概括：

> 嵌入式芯片 = 处理器核心 + 片上存储器 + 外设控制器 + 总线 + 供电/时钟/复位

### 与通用 CPU 的差异

| 对比项 | 通用 CPU（PC/服务器） | 嵌入式芯片 |
| --- | --- | --- |
| 设计目标 | 峰值算力、通用性 | 特定功能、性价比、低功耗 |
| 集成度 | CPU 单独一颗，外设靠芯片组 | 高度集成，SoC 单芯片方案 |
| 封装形态 | LGA/BGA 大封装、需散热器 | QFP/QFN/BGA，常可无散热器 |
| 功耗 | 数十瓦～数百瓦 | 毫瓦～数瓦 |
| 供货周期 | 换代快（1～2 年） | 生命周期长（5～15 年） |
| 软件形态 | 通用 OS + 应用 | 固件、RTOS、裁剪后的 Linux |
| 可靠性要求 | 商用级 | 可到工业级/车规级/宇航级 |

## 二、嵌入式芯片的分类

### 按功能定位分

| 类型                | 说明                          | 典型型号                            | 应用             |
| ----------------- | --------------------------- | ------------------------------- | -------------- |
| **MCU** 微控制器      | 单芯片集成 CPU+Flash+RAM+外设      | STM32F103、ESP32、GD32、ATmega328P | 家电、传感器、电机控制    |
| **MPU** 微处理器      | 需外接 DDR，性能强，跑 Linux/Android | i.MX6/8、全志 H3、树莓派 SoC           | HMI、网关、智能终端    |
| **DSP** 数字信号处理器   | 硬件乘加、流水线优化，擅长实时信号运算         | TI C2000/C6000、ADI SHARC        | 音频、电机 FOC、通信基带 |
| **FPGA** 现场可编程门阵列 | 硬件逻辑可编程、并行度高                | Xilinx Artix、Altera Cyclone     | 高速采集、图像、协议加速   |
| **SoC** 片上系统      | CPU+GPU+NPU+外设等完整系统         | 高通骁龙、瑞芯微 RK3568                 | 手机、AIoT、边缘计算   |
| **ASIC** 专用集成电路   | 为特定用途定制，量产单价低               | 各类定制芯片、矿机芯片                     | 大批量消费电子、专用设备   |
| **CPLD** 复杂可编程逻辑  | 规模小于 FPGA，做胶合逻辑             | Altera MAX 系列                   | 时序配合、接口转换      |

### 按处理器位宽 / 性能档次分

| 档次 | 位宽 | 主频 | 典型用途 |
| --- | --- | --- | --- |
| 8 位 | 8 bit | 1～50 MHz | 玩具、简单控制、教学（8051、PIC、AVR） |
| 16 位 | 16 bit | 10～50 MHz | 家电、仪表（MSP430、PIC24） |
| 32 位 | 32 bit | 24 MHz～1 GHz+ | 主流嵌入式（ARM Cortex-M/R/A、RISC-V） |
| 64 位 | 64 bit | 1 GHz+ | 高端应用处理器、AI 边缘盒子 |

### 按内核架构分

- **ARM**（主流，授权模式）：
  - **Cortex-M**：M0/M0+/M3/M4/M7/M33，微控制器内核，带 NVIC、低功耗、可选 FPU/DSP。
  - **Cortex-R**：R5/R7/R52，实时与安全关键（车规、存储控制器）。
  - **Cortex-A**：A53/A55/A72/A78，应用处理器，跑 Linux/Android，带 MMU。
  - **Cortex-M 与 Cortex-A 的核心区别**：有无 MMU、是否支持多级流水与乱序、是否面向操作系统。
- **RISC-V**：开源指令集，无授权费，模块化扩展（RV32I/RV64GC），国产与学术领域增长快。
- **x86**：Intel Atom、AMD Embedded，兼容 PC 生态，用于工控与网关。
- **MIPS / PowerPC**：网络设备、汽车老平台仍有存量。
- **8051 / AVR / PIC**：经典 8 位机，生态成熟、资料多、成本极低。

### 1. 处理器核心（Core）

- **流水线**：取指 → 译码 → 执行 → 访存 → 写回；3 级流水常见于 MCU。
- **寄存器组**：通用寄存器（R0–R12）、栈指针 SP、链接寄存器 LR、程序计数器 PC。
- **ALU / FPU / DSP 扩展**：浮点单元、SIMD 加速。
- **特权级与模式**：如 Cortex-M 的 Thread/Handler 模式 + 特权/非特权，用于 RTOS 与安全隔离。

### 2. 存储器

| 类型 | 特性 | 用途 |
| --- | --- | --- |
| Flash（片上） | 掉电不丢失，可擦写有限次（约 1 万～10 万次） | 存放程序代码、常量 |
| SRAM | 快、无需刷新、贵、容量小 | 运行数据、堆栈、缓存 |
| ROM / OTP | 出厂固化、不可改 | 启动代码、密钥 |
| EEPROM / 模拟 EEPROM | 字节可擦写，寿命长 | 配置参数、校准值 |
| 外扩 DDR / SDRAM | 容量大、便宜、需初始化 | Linux 系统的运行内存 |
| 外扩 NAND / eMMC / SD | 大容量非易失 | 文件系统、固件、日志 |
| 外部 QSPI Flash | 串行、引脚少 | 存放镜像、XIP 执行 |

> **XIP（eXecute In Place）**：代码直接在 Flash 中执行，省 RAM 但速度受 Flash 限制。

### 3. 时钟与复位

- **时钟源**：内部 RC（HSI/LSI，快速启动、精度低）、外部晶振（HSE/LSE，精度高）。
- **PLL**：倍频得到 CPU 与外设时钟。
- **时钟树**：AHB/APB 分频，各外设独立门控（省电关键）。
- **复位源**：上电复位 POR、掉电复位 PDR、看门狗复位、软件复位、外部引脚复位。
- **低功耗模式**：Sleep / Stop / Standby（Cortex-M），关机与唤醒源管理。

### 4. 外设控制器

| 外设 | 作用 | 关键参数 |
| --- | --- | --- |
| GPIO | 通用输入输出 | 电平、上下拉、开漏、复用功能 |
| UART/USART | 异步串口 | 波特率、校验、DMA |
| SPI | 同步高速串行 | 模式 CPOL/CPHA、片选、速率 |
| I²C | 双线低速总线 | 地址、上拉电阻、时钟拉伸 |
| CAN / CAN-FD | 现场总线 | 差分、仲裁、报文 ID |
| USB | 设备/主机/OTG | 全速/高速、CDC/HID/MSC |
| 以太网 MAC | 网络通信 | 需外接 PHY、RMII/MII |
| ADC / DAC | 模拟转换 | 分辨率（12/16 bit）、采样率、参考电压 |
| 定时器 TIM | 定时、计数、PWM、输入捕获 | 预分频、自动重载、通道数 |
| 比较器 / OPAMP | 模拟比较与放大 | 阈值、迟滞 |
| DMA | 不占 CPU 搬数据 | 通道数、触发源、循环模式 |
| RTC | 实时时钟 | 独立供电、闹钟唤醒 |
| 看门狗 WDT | 死机自动复位 | 超时时间、窗口模式 |
| 加密引擎 | AES/SHA/TRNG | 安全启动、密钥存储 |

### 5. 总线与互连

- **AHB / AXI**：高速总线，接 CPU、DMA、内存控制器。
- **APB**：低速总线，接 UART、I²C 等慢速外设。
- **总线矩阵 / 交叉开关**：多主设备并发访问，减少阻塞。
- **地址映射**：每个外设对应一段寄存器地址，通过读写寄存器控制硬件。

## 四、关键性能参数（选型必看）

| 参数 | 含义 | 关注点 |
| --- | --- | --- |
| 内核与主频 | 如 Cortex-M4 @ 168 MHz | 算力是否够（可用 DMIPS/MHz、CoreMark 比较） |
| Flash / RAM 容量 | 程序与数据空间 | 留 20%～30% 余量给后续升级 |
| 工作电压 | 1.8V / 3.3V / 5V | 与传感器、通信模块电平兼容 |
| 功耗 | 运行/睡眠/待机电流 | 电池供电设备的核心指标 |
| 封装与引脚数 | LQFP48、QFN32、BGA | 影响 PCB 层数与焊接难度 |
| 工作温度 | 商业 0～70℃、工业 −40～85℃、车规 −40～125℃ | 环境适应性 |
| 外设数量 | UART/SPI/I²C/ADC 通道、定时器个数 | 是否够接全部外设 |
| 运算与加速 | FPU、DSP、NPU、硬件除法 | 浮点/FFT/AI 推理需求 |
| 安全功能 | 安全启动、TrustZone、加密引擎、唯一 ID | 版权保护、通信加密 |
| 供应与生态 | 是否有货、寿命承诺、工具链与文档 | 量产可行性与开发效率 |

### 常见的算力衡量方式

- **DMIPS**：Dhrystone 每秒百万条指令，Cortex-M3 约 1.25 DMIPS/MHz。
- **CoreMark / CoreMark/MHz**：更贴近实际负载的综合基准。
- **MFLOPS / GFLOPS**：浮点运算能力，DSP/NPU 常用。
- **TOPS**：AI 推理算力，1 TOPS ≈ 每秒 1 万亿次 8 位乘加。

## 五、芯片的等级与认证

| 等级 | 温度范围 | 标准/特点 | 典型场景 |
| --- | --- | --- | --- |
| 商业级（Consumer） | 0～70℃ | 成本最低 | 消费电子、玩具 |
| 工业级（Industrial） | −40～85℃（部分 −40～105℃） | 抗干扰与寿命要求更高 | 工控、电力、仪器 |
| 车规级（Automotive） | −40～125℃ | AEC-Q100 认证、功能安全 ISO 26262（ASIL A～D） | 汽车电子 |
| 军工/宇航级 | −55～125℃+ | 抗辐照、军标 | 航天、国防 |
| 医疗级 | 视用途 | IEC 60601 等 | 医疗设备 |

> 选型时注意：**同型号不同后缀**可能对应不同温度等级与封装，不能混用。

## 六、封装与引脚

| 封装 | 特点 | 适用 |
| --- | --- | --- |
| DIP | 直插、手焊友好、体积大 | 教学、原型 |
| SOP / SSOP | 贴片、引脚外露 | 简单电路 |
| QFP / LQFP | 四边引脚、易焊易测 | 主流 MCU |
| QFN | 无引脚、体积小、散热好、需底部焊盘 | 小型化产品 |
| BGA | 球栅阵列、引脚多、需专业返修 | MPU/SoC |
| WLCSP | 晶圆级、最小、最难焊 | 手机/穿戴 |

**引脚复用（Pin Mux）**：一颗引脚常有多个功能（如 PA9 = USART1_TX / TIM1_CH2），由寄存器配置选择，是硬件设计的核心约束。

## 八、选型方法（实操清单）

按优先级逐条过筛：

1. **功能需求**：需要哪些外设？数量够不够（串口/ADC 通道/定时器）？
2. **算力与内存**：算法复杂度 → 主频、是否需 FPU/DSP/NPU；代码量 → Flash/RAM 余量。
3. **功耗与供电**：电池还是市电？低功耗模式电流是否达标？
4. **环境等级**：温度范围、抗干扰、是否需车规/医疗认证。
5. **封装与 PCB**：引脚数、层数、焊接工艺是否与产线匹配。
6. **软件生态**：SDK、HAL、RTOS 支持、Linux 主线支持、社区与中文资料。
7. **成本与供货**：单价、最小起订量、原厂寿命承诺、是否有替代型号（Pin-to-Pin 兼容）。
8. **安全与合规**：安全启动、加密、认证（CE/FCC/CCC）需求。
9. **开发工具**：官方 IDE、调试器（ST-Link/J-Link/DAPLink）、仿真器价格。

> 经验法则：**先满足硬约束（外设/温度/认证），再比算力与成本**；能用成熟型号就别用冷门型号。

## 九、开发与使用要点

### 1. 启动过程（MCU 典型）

```
上电 → 从 Flash 固定地址取向量表 → 取初始 SP 与 Reset_Handler
     → 配置时钟/RCC → 初始化 .data/.bss 段 → 调用 main() → 主循环/RTOS 启动
```

MPU/Linux 类芯片则多一级：BootROM → SPL/U-Boot → 内核 → 根文件系统。

### 2. 寄存器级操作三件套

1. **使能时钟**（忘了开时钟是最常见的"外设不工作"原因）；
2. **配置引脚复用与电气属性**；
3. **配置外设寄存器**（含中断、DMA），再使能。

### 3. 烧录与调试接口

| 接口 | 说明 |
| --- | --- |
| JTAG | 5 线，功能全，可边界扫描 |
| SWD | 2 线（SWCLK+SWDIO），ARM 主流，省引脚 |
| ISP / Bootloader | 串口或 USB 下载，无需调试器 |
| DFU / Mass Storage | USB 方式升级 |
| OTA | 远程升级，需双分区 + 校验 + 回滚 |

### 4. 常见坑

- **电平不匹配**：3.3V MCU 直连 5V 器件可能损坏或读不到。
- **Flash 寿命与擦写粒度**：频繁写同一扇区会提前损坏，需磨损均衡。
- **RAM 不够**：大数组放栈上容易溢出，应静态分配或放外部 RAM。
- **引脚冲突**：外设复用与调试口（SWD）被占用导致无法再下载。
- **中断优先级**：优先级反转、临界区过长导致丢中断。
- **晶体不起振**：负载电容不匹配、布线过长、旁路电容位置不当。
- **电源纹波**：ADC 精度差、Wi-Fi 断连常源于电源与地设计。
- **散热**：高主频 MCU/MPU 长时间满载需考虑温升与降频。

## 十一、小结

- 嵌入式芯片的本质是**为特定应用高度集成的片上系统**，权衡的是功能、算力、功耗、成本与可靠性。
- 理解一颗芯片，抓住四条主线：**内核（算什么）→ 存储器（放哪里）→ 外设与总线（连什么）→ 时钟与电源（怎么跑起来）**。
- 选型先过硬约束（外设数量、温度等级、认证、供货），再比算力与价格。
- 上手新芯片的标准流程：读数据手册（Datasheet）+ 参考手册（Reference Manual）+ 勘误表（Errata）→ 跑通时钟与 GPIO → 逐个点亮外设。
