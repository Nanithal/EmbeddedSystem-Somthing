> 记录时间：2026-02-14

## 一、什么是最小系统

**最小系统**是指能让一颗 MCU **正常上电、运行程序、并被下载调试** 的最少外围电路。有了它，芯片就"活了"，其余功能都是在此基础上叠加。

```
┌─────────────────────── STM32 最小系统 ────────────────────────┐
│                                                              │
│   ① 电源电路          ② 时钟电路          ③ 复位电路          │
│   ┌──────────┐       ┌──────────┐      ┌──────────┐         │
│   │5V→3.3V   │       │8 MHz HSE │      │10k 上拉   │         │
│   │LDO+去耦  │       │32.768kHz │      │100nF 到地 │         │
│   │多路 100nF│       │LSE(可选) │      │复位按键    │         │
│   └────┬─────┘       └────┬─────┘      └────┬─────┘         │
│        │                  │                │                │
│        └──────────┬───────┴────────┬───────┘                │
│                   ↓                ↓                        │
│            ┌──────────────────────────────────┐             │
│            │        STM32 芯片主体             │             │
│            │  VDD / VSS / VDDA / VBAT         │             │
│            │  OSC_IN / OSC_OUT                │             │
│            │  NRST / BOOT0 / BOOT1            │             │
│            │  PA13(SWDIO) / PA14(SWCLK)       │             │
│            └──────────────────────────────────┘             │
│                   ↑                ↑                        │
│   ④ Boot 配置          ⑤ 下载调试口           ⑥ 指示/扩展    │
│   ┌──────────┐       ┌──────────┐      ┌──────────┐         │
│   │BOOT0 10k │       │SWD 4 线   │      │电源 LED   │         │
│   │下拉到地   │       │VCC/GND/IO │      │串口 TX/RX │         │
│   │BOOT1(部分)│      │RST        │      │测试点      │         │
│   └──────────┘       └──────────┘      └──────────┘         │
└──────────────────────────────────────────────────────────────┘
```

> 一句话：**电源 + 时钟 + 复位 + Boot 配置 + 下载口 = 最小系统**。指示灯与串口是强烈建议加的"调试眼"。

## 二、六大组成部分

### ① 电源电路

| 要点 | 说明 |
| --- | --- |
| 主电压 | STM32 主流为 **3.3 V**（范围 2.0~3.6 V，F1 为 2.0~3.6 V，F4 为 1.8~3.6 V） |
| 供电来源 | USB 5 V / DC 5~12 V / 电池；经 LDO 或 DCDC 降到 3.3 V |
| 常用 LDO | **AMS1117-3.3**（便宜但压差大、静态电流大）、**RT9013**、**ME6211**、**SPX3819**（低噪声） |
| 去耦电容 | **每个 VDD 引脚配 1 个 100 nF**，紧贴引脚放置；全局再加 **4.7~10 μF** 钽电容或陶瓷电容 |
| VDDA | 模拟电源（ADC 用），经**磁珠或 10 Ω 电阻**从 VDD 隔离，加 10 nF + 1 μF 去耦 |
| VREF+ | 若有独立引脚（F4 的 100 脚以上封装），接干净基准或接 VDDA |
| VBAT | 接 3.3 V；若用 RTC/备份域，接纽扣电池（CR1220）并通过二极管隔离 |
| VSS | 全部接地，模拟地与数字地单点相连（或用 0 Ω 电阻） |
| VCAP | **F4/F7/L4 等有内部稳压器的型号**需在 VCAP1/VCAP2 接 **2.2 μF 低 ESR 电容**（漏接会无法工作！） |
| 保护 | 输入端加自恢复保险丝 / TVS / 防反接二极管 |

**F103C8T6 电源引脚接法**

| 引脚 | 接法 |
| --- | --- |
| VDD_1/2/3（24、36、48 脚） | 3.3 V，各配 100 nF |
| VSS_1/2/3 | GND |
| VDDA（9 脚） | 经磁珠接 3.3 V + 10 nF/1 μF |
| VSSA（8 脚） | GND |
| VBAT（1 脚） | 接 3.3 V（不用 RTC 时也**不能悬空**） |

> **经典坑**：VBAT 悬空可能导致芯片不稳定；VDDA 未接会导致 ADC 完全不可用。

### ② 时钟电路

| 时钟 | 器件 | 匹配电容 | 说明 |
| --- | --- | --- | --- |
| **HSE**（高速外部） | 8 MHz 无源晶振（贴片 5032/3225） | 通常 **20 pF**（10~22 pF） | 主时钟源，PLL 倍频到 72/168 MHz |
| **LSE**（低速外部） | 32.768 kHz 晶振 | 通常 **5~12 pF** | RTC 走时用，不用 RTC 可省 |
| HSI | 芯片内部 RC 8/16 MHz | — | 备用，精度差，可省外部晶振跑低速应用 |

**晶振电路要点**

```
       ┌─── OSC_IN ───┬────────────┐
       │              │            │
   ┌───┴───┐      ┌───┴───┐    ┌───┴───┐
   │ 8MHz  │      │C1 20pF│    │Rf 1MΩ │  ← 反馈电阻（多数情况芯片内部已有）
   └───┬───┘      └───┬───┘    └───┬───┘
       │              │            │
       └─── OSC_OUT ──┴────────────┘
                      │
                     GND
```

- **匹配电容选值**：`C ≈ 2 × (CL − Cs)`，其中 CL 为晶振规格负载电容（常见 12 pF 或 20 pF），Cs 为 PCB 杂散电容（约 3~5 pF）。CL=12 pF 时取约 15~18 pF。
- **走线**：晶振**紧贴芯片**，走线尽量短、加包地、不要跨越其他信号；晶振下方避免走线。
- **不要用探头直碰 OSC_IN**：示波器探头电容会让晶振停振，测频率应看 MCO 输出引脚。
- **无源晶振 vs 有源晶振**：有源晶振（OSC）输出接 OSC_IN，OSC_OUT 悬空，成本高但起振可靠。
- **可省 HSE 吗**：可以（用 HSI），但串口波特率、USB、CAN 对时钟精度敏感，**建议保留 HSE**。

### ③ 复位电路

```
        3.3V
         │
        ┌┴┐  10 kΩ（部分型号内部已有弱上拉，仍需外部）
        │ │
        └┬┘
         ├────────── NRST
         │
      ┌──┴──┐
      │按键 │         ┌──────┐
      └──┬──┘         │100nF │
         │            └──┬───┘
        GND             GND
```

| 要点 | 说明 |
| --- | --- |
| 上拉电阻 | 10 kΩ 到 3.3 V |
| 滤波电容 | **100 nF 到地**（抗干扰、保证上电可靠复位；漏掉会出现"上电偶尔不启动"） |
| 复位按键 | 并联在 NRST 与 GND 之间，用于手动复位 |
| 复位时间 | RC 时间常数 ≈ 1 ms，足够覆盖电源上升时间 |
| 内部复位源 | 上电复位 POR / 掉电复位 PDR / 看门狗 / 软件复位，不需外部干预 |
| 其他复位引脚 | 部分型号有 **NRST + PDR_ON**（F4 有 PDR_ON 引脚，需接 VDD 或 GND 使能内部复位） |

> **注意**：调试器（ST-Link）的 RST 引脚接 NRST，可实现"复位后立即 halt"，对下载调试很重要。

### ④ Boot 配置电路

| 引脚 | 作用 | 最小系统接法 |
| --- | --- | --- |
| **BOOT0** | 选启动区 | **10 kΩ 下拉到 GND**（从主 Flash 启动）；可加跳线帽或按键用于进入 ISP |
| **BOOT1**（F1 的 PB2） | 配合 BOOT0 | 10 kΩ 下拉到 GND；**F4 起取消 BOOT1，改由选项字节 nBOOT1 配置** |

**实践推荐**：BOOT0 用 10 kΩ 下拉 + 可选跳线到 3.3 V，方便量产时用串口 ISP 下载。

> 同一引脚 PB2 在 F1 上既是 BOOT1 又是普通 IO，若当普通 IO 用需注意启动时电平。

### ⑤ 下载调试接口（SWD）

| 引脚 | 信号 | 说明 |
| --- | --- | --- |
| PA13 | **SWDIO** | 数据线 |
| PA14 | **SWCLK** | 时钟线 |
| NRST | 复位 | 建议引出（支持复位下载） |
| 3.3V / GND | 电源 | 建议引出（可给目标板供电，注意电流） |

**标准 SWD 排针定义（2×5，2.54 mm 或 1.27 mm）**

| 引脚 | 信号 | 引脚 | 信号 |
| --- | --- | --- | --- |
| 1 | VCC(3.3V) | 2 | SWDIO |
| 3 | GND | 4 | SWCLK |
| 5 | GND | 6 | SWO（可选，ITM 跟踪） |
| 7 | KEY（空脚） | 8 | NC |
| 9 | GND | 10 | NRST |

> **最少可用 4 根线**：3.3V、GND、SWDIO、SWCLK。

**常见坑**：把 PA13/PA14 复用为普通 IO 或进入低功耗后，会**无法再连接 SWD**；解决方式是 BOOT0=1 进系统存储器擦除，或按住复位后立即下载。

### ⑥ 指示灯与调试串口（强烈建议）

| 器件 | 接法 | 作用 |
| --- | --- | --- |
| 电源指示灯 | 3.3 V → 1 kΩ → LED → GND | 一眼判断是否上电 |
| 运行指示灯 | PC13 或任意 IO → 1 kΩ → LED → GND | 判断程序是否在跑 |
| 串口 TX | PA9（USART1_TX）→ USB-TTL 的 RX | printf 调试输出（最重要） |
| 串口 RX | PA10（USART1_RX）← USB-TTL 的 TX | 接收命令 |
| 测试点 | VDD/GND/NRST/SWD 焊盘 | 便于量测与飞线 |

## 三、不同芯片型号的引脚差异

| 型号 | 电源引脚 | 特殊引脚 | 注意 |
| --- | --- | --- | --- |
| **STM32F103C8T6** | VDD×3、VSS×3、VDDA、VSSA、VBAT | 无 VCAP，无 PDR_ON | BOOT1=PB2 |
| STM32F103ZET6 | VDD 更多（100/144 脚） | 有独立 VREF+ | BOOT1=PB2 |
| **STM32F407ZGT6** | VDD、VDDA、VBAT + **VCAP1/VCAP2** | **PDR_ON**、VREF+ | VCAP 必须接 2.2 μF；PDR_ON 接 VDD |
| STM32F429 | 同上 | 有 SDRAM/LCD 接口 | 高速外设更多，电源要求更高 |
| STM32F767/H743 | VDD/VDDLDO/VDDA/VBAT + VCAP×2 | SMPS 相关引脚（H7 部分型号） | 需严格按数据手册接法 |
| STM32L431/U575 | VDD/VDDA/VBAT + VCAP | 超低功耗，注意 VLCD 等 | 低功耗引脚配置影响待机电流 |
| STM32G071 | VDD/VDDA/VBAT | 无 VCAP | — |

> **铁律**：设计前必看对应型号的 **Datasheet 第 4 章（Pinouts and pin description）**，逐脚确认"必须接什么"，不能凭经验类比。

## 四、上电时序与可靠性

### 1. 上电要求

| 项目 | 要求 |
| --- | --- |
| VDD 上升时间 | 需在规格内（一般要求单调上升，不要有长时间平台） |
| VDD 与 VDDA | 同时或 VDDA 不晚于 VDD 太多上电 |
| 复位释放 | NRST 需在 VDD 稳定后保持足够时间（POR 内部保证 + 外部 RC 兜底） |
| BOR 等级 | 通过选项字节设置欠压复位阈值（如 2.0/2.3/2.5/2.7 V） |
| PVD | 可编程电压检测器，可在低压时提前预警（写 Flash 前必查） |

### 2. 电源完整性

- **去耦电容靠近引脚**：距离 > 5 mm 时去耦效果大幅下降。
- **地平面完整**：双层板尽量铺地，关键器件下方不要被割裂。
- **模拟/数字分地**：VDDA 与 VDD 用磁珠隔离，VSSA 单点接 GND。
- **LDO 散热**：AMS1117 从 5 V 降到 3.3 V，电流 200 mA 时功耗 (5−3.3)×0.2 ≈ 0.34 W，需注意温升。
- **峰值电流**：Wi-Fi/BLE 模块瞬时电流可达数百 mA，需就近大电容（100 μF 级）。

### 关键元件选型建议

| 元件 | 建议 |
| --- | --- |
| LDO | 优先 **ME6211/RT9013**（静态电流小、压差低），避免 AMS1117 用于电池设备 |
| 晶振 | 选 **CL=12 pF 的小型贴片**，ESR 低、起振可靠；避免二手/杂牌 |
| 电容 | 去耦用 **X7R 陶瓷**，不要用 Y5V（容值随电压温漂大） |
| 按键 | 加 100 nF 硬件消抖，或软件消抖 |
| 排针 | SWD 用 2.54 mm（方便杜邦线）或 1.27 mm（省空间） |

## 六、PCB 布局布线要点

| 项目 | 要点 |
| --- | --- |
| **去耦电容** | 紧贴电源引脚，先过电容再进引脚；电容地就近打过孔到地平面 |
| **晶振** | 靠近芯片、走线短且等长、包地、周围禁布其他信号、下方整块地 |
| **NRST** | 走线短，远离高频信号，可串 100 Ω 抗干扰 |
| **BOOT0** | 下拉电阻靠近引脚，避免长走线引入干扰 |
| **SWD** | SWDIO/SWCLK 尽量等长直连，避免与高速信号并行 |
| **USB** | D+/D− 差分 90 Ω、等长、包地；ESD 器件靠近接口 |
| **地平面** | 双层板底层尽量完整铺地，避免大面积开槽 |
| **电源线宽** | 按电流计算（1 A 约需 20 mil 以上），3.3 V 主干加粗 |
| **散热** | LDO 与 MCU 下方铺铜散热，必要时加过孔阵列 |
| **丝印** | 标注引脚名与测试点，方便调试 |

## 七、焊接与首次上电检查

### 焊接顺序

```
① 先焊 LDO 与电源部分 → 上电测 3.3 V（此时不焊 MCU，避免虚焊损坏）
② 测 3.3 V 正常、无短路 → 焊 MCU、电容
③ 上电复测 3.3 V 与各 VDD 引脚电压
④ 焊晶振与匹配电容 → 检查起振
⑤ 焊复位、BOOT0、SWD 排针
⑥ 焊 LED、串口、其余外设
```

### 上电必查清单

| 检查项 | 方法 | 期望结果 |
| --- | --- | --- |
| 3.3 V 电源 | 万用表测 VDD-GND | 3.3 V ±5% |
| 各 VDD 引脚 | 逐脚量 | 均有 3.3 V（无虚焊） |
| 是否短路 | 上电前用电阻档测 VDD-GND | 数百欧以上（不能接近 0） |
| 电流 | 串万用表测总电流 | F103 空跑约 20~40 mA（异常大 = 有短路/闩锁） |
| 复位电平 | 测 NRST | 3.3 V（按下按键为 0 V） |
| BOOT0 | 测 BOOT0 | 0 V |
| 晶振 | 调试器看 RCC 寄存器 / MCO 输出 | HSE 起振、SYSCLK 正确 |
| SWD 连接 | ST-Link 连接目标 | 能读到 IDCODE（如 0x1BA01477） |
| 下载运行 | 下载点灯程序 | LED 闪烁 |

### 晶振起振验证（推荐做法）

```c
/* 把 SYSCLK/8 从 MCO 引脚输出，用示波器/频率计较准测量 */
RCC->CFGR &= ~RCC_CFGR_MCO;
RCC->CFGR |= RCC_CFGR_MCO_SYSCLK;         /* MCO = SYSCLK */
RCC->CFGR |= RCC_CFGR_MCO_PRE_1;          /* 不分频（注意 MCO 最高频率限制）*/
/* F1 的 MCO 引脚 PA8；测到 9 MHz 即证明 SYSCLK = 72 MHz */
```

> **不要直接测 OSC_IN/OSC_OUT**：探头电容会导致停振或频偏。

## 八、常见故障排查

| 现象 | 可能原因 | 排查/解决 |
| --- | --- | --- |
| 完全无反应、SWD 连不上 | 3.3 V 异常、VDD 虚焊、VCAP 漏接（F4） | 逐脚量电压，查 VCAP 电容 |
| 上电偶尔不启动 | NRST 缺 100 nF、电源上升太慢、BOR 设置不当 | 加复位电容、调电源、设 BOR |
| 晶振不起振 | 匹配电容不匹配、晶振坏、走线长、未启振 | 换 20 pF、试内部 HSI、缩短走线 |
| 串口乱码 | 用 HSI 而非 HSE、波特率算错、时钟未配 | 确认 HSE 起振、核算波特率 |
| 下载后只能跑一次 | 禁用了 SWD 引脚、进低功耗 | BOOT0=1 擦除，或复位瞬间下载 |
| 电流异常大（>200 mA） | 电源短路、引脚对地短路、IO 冲突、闩锁 | 断电测阻抗、逐个断外设 |
| 程序跑飞 | 栈溢出、无看门狗、电源纹波 | 加大栈、开 IWDG、加去耦 |
| ADC 读数不准 | VDDA 未接/未滤波、VREF 不稳、地噪声 | 补 VDDA 滤波、加磁珠、多次平均 |
| BOOT0 悬空导致行为异常 | 干扰误入 Bootloader | 10 kΩ 下拉 |
| VBAT 悬空导致不稳定 | 备份域供电异常 | 接 3.3 V 或电池 |
| 待机电流下不来 | IO 悬空、外设时钟未关、调试口供电 | 悬空脚配模拟输入、关外设时钟 |

## 十一、小结

- **最小系统 = 电源（3.3 V + 去耦）+ 时钟（8 MHz HSE，可选 LSE）+ 复位（10 k 上拉 + 100 nF）+ Boot 配置（BOOT0 下拉）+ SWD 调试口**。
- 三条最容易犯的错：**VCAP 漏接（F4+ 直接不工作）、BOOT0 悬空（跑不起来）、NRST 缺电容（上电偶发失败）**。
- 三个必须记住的强制接法：**VBAT 不能悬空、VDDA 必须接并滤波、每个 VDD 都要 100 nF**。
- 布线上，**晶振紧贴芯片、去耦紧贴引脚、地平面完整**是稳定性的三根支柱。
- 上电检查顺序：**先电源（不焊 MCU）→ 再焊 MCU 复测 → 然后晶振 → 最后 SWD 连通下载**。
- 调试三件宝：**串口 printf、运行 LED、SWD 单步**。
