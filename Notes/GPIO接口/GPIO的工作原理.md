> 记录时间：2026-02-14

---

## 一、GPIO 是什么

**GPIO（General Purpose Input/Output，通用输入输出）** 是 MCU 上最基本、最常用的外设：一根可以被软件配置为**输入**或**输出**、并读取或输出**高低电平**的引脚。

它的本质是**连接数字世界与外部世界的门**：

```
MCU 内核 ── 总线 ── GPIO 寄存器 ── 输出驱动器/输入缓冲 ── 引脚 ── 外部电路
                                    （数字逻辑）           （电压/电流）
```

### 核心能力

| 能力 | 说明 |
| --- | --- |
| 数字输出 | 输出高（3.3 V）或低（0 V），驱动 LED、继电器、逻辑输入 |
| 数字输入 | 读取外部电平（按键、传感器数字输出、通信信号） |
| 电平检测 | 判断高/低，配合中断实现事件触发 |
| 复用功能（AF） | 引脚让给 UART/SPI/I²C/TIM 等外设使用 |
| 模拟功能 | 部分引脚可作 ADC 输入 / DAC 输出（模拟模式） |
| 中断源 | 电平/边沿变化触发 EXTI 外部中断 |

> **重要认知**：GPIO 输出的是**逻辑电平**，不是"电源"。它能提供的电流有限（STM32 单脚约 ±20 mA，总和有限制），驱动大负载必须加三极管/MOS/驱动芯片。

## 二、GPIO 内部结构

以 STM32 的典型 GPIO 单元为例，内部由四部分组成：**保护电路 + 输出驱动 + 输入通路 + 配置寄存器**。

![[Pasted image 20261009122309.png]]


```
                         VDD (3.3V)
                            │
              ┌─────────────┴─────────────┐
              │      上拉电阻 (~40kΩ)      │  ← 可开关
              │  ┌──────────────────────┐ │
              │  │                      │ │
   输出数据 ──┼──┤ 输出控制逻辑            │ │
   (ODR 寄存器)│  │  ┌─────────┐         │ │
              │  └──┤ P-MOS   ├─────────┼─┼──── 引脚 Px
   输出使能 ──┼─────┤         │          │ │      │
              │     └─────────┘         │ │      │
              │     ┌─────────┐         │ │   ┌──┴──┐  保护二极管
              │     │ N-MOS   │         │ │   │  ↑  │  (VDD)
              │     └─────────┘         │ │   └──┬──┘
              │      下拉电阻 (~40kΩ)     │ │      │
              └─────────────┬───────────┘ │   ┌──┴──┐  保护二极管
                            │             │   │  ↓  │  (VSS)
                            │             │   └──┬──┘
   输入数据 ←────────────────┤ 施密特触发器  │      │
   (IDR 寄存器)              │ (Schmitt)   │     GND
                            └─────────────┘
   模拟输入 ──────────────────────────────────→ ADC/DAC
```

### 1. 保护电路（上下两个二极管）

- **上二极管**：引脚 → VDD，把高于 VDD+0.7 V 的电压钳位（防过压）。
- **下二极管**：VSS → 引脚，把低于 −0.7 V 的电压钳位（防负压）。
- 作用：抗静电（ESD）与轻微过压保护。
- **限制**：只能钳位**微弱电流**（一般 < 5 mA 持续），长时间大电流会烧毁；不能当稳压用，也不能直接接 5 V 强驱动源。

### 2. 输出驱动（双 MOS 管）

```
        VDD
         │
     ┌───┴───┐  P-MOS（上管）
     │       │  导通 → 引脚输出高电平
     └───┬───┘
         ├──────── 引脚
     ┌───┴───┐
     │       │  N-MOS（下管）
     └───┬───┘  导通 → 引脚输出低电平
         │
        VSS
```

- **推挽输出（Push-Pull）**：上管与下管交替导通，主动输出高与低，驱动能力强。
- **开漏输出（Open-Drain）**：**只保留下管**，上管永久关闭。
  - 只能主动输出低电平；高电平必须靠**外部上拉电阻**拉到某电压。
  - 用途：**电平转换**（上拉到 5 V 即可输出 5 V 逻辑）、**I²C 总线**、**线与（wired-AND）多设备共享**。

### 3. 输入通路

| 元件 | 作用 |
| --- | --- |
| 施密特触发器 | 把带噪声的模拟波形整形成干净的数字电平，提供迟滞抗抖动 |
| 上拉/下拉电阻 | 约 30~50 kΩ，可软件开关；确保悬空引脚有确定电平 |
| IDR 寄存器 | 输入数据寄存器，读它即读引脚当前电平 |
| 模拟开关 | 配置为模拟模式时，把引脚直连 ADC/DAC，断开数字通路 |

### 4. 配置寄存器

引脚的行为模式完全由寄存器位决定（见第五节）。

## 三、八种工作模式

STM32 的 GPIO 可配置为 **4 种输入 + 4 种输出**：

| 编号  | 模式                          | 方向  | 典型用途                        |
| --- | --------------------------- | --- | --------------------------- |
| 1   | **浮空输入**（Input Floating）    | 输入  | 外部已有上下拉时（如 I²C 总线的 SCL/SDA） |
| 2   | **上拉输入**（Input Pull-up）     | 输入  | 按键接地的场合（最常用）                |
| 3   | **下拉输入**（Input Pull-down）   | 输入  | 按键接 VDD 的场合                 |
| 4   | **模拟输入**（Analog）            | 输入  | ADC 采集、低功耗省电（悬空脚建议设此模式）     |
| 5   | **推挽输出**（Output Push-Pull）  | 输出  | LED、驱动数字输入、PWM              |
| 6   | **开漏输出**（Output Open-Drain） | 输出  | I²C、电平转换、多设备共享线             |
| 7   | **复用推挽**（AF Push-Pull）      | 输出  | UART TX、SPI SCK/MOSI、PWM 输出 |
| 8   | **复用开漏**（AF Open-Drain）     | 输出  | I²C 的 SCL/SDA、CAN           |

![[Pasted image 20261009122847.png]]

### 模式选择思路

```
这个引脚要干什么？
├─ 读外部电平 ──→ 外部有上拉？→ 浮空输入
│                需要内部上拉？→ 上拉输入
│                需要内部下拉？→ 下拉输入
├─ 输出高低电平 ─→ 只需单向拉低/需要电平转换？→ 开漏输出
│                  需要主动输出高低？→ 推挽输出
├─ 交给外设使用 ─→ 复用推挽（UART/SPI/TIM）
│                  复用开漏（I²C）
└─ 给 ADC 用 ────→ 模拟输入
```

> **关键区分**：普通"输出模式"由软件写 ODR 控制电平；"复用模式"由外设（如 USART）控制电平。**配置外设引脚必须选复用模式**，否则外设无法驱动引脚。

## 四、关键电气参数

### 1. 电压与电平

| 参数 | 典型值 | 说明 |
| --- | --- | --- |
| VDD | 3.3 V（2.0~3.6 V） | I/O 电平基准 |
| VOH（输出高） | ≥ VDD − 0.4 V | 输出高电平最小值（与负载电流有关） |
| VOL（输出低） | ≤ 0.4 V | 输出低电平最大值 |
| VIH（输入高阈值） | ≥ 0.7 × VDD ≈ 2.3 V | 高于此判为高 |
| VIL（输入低阈值） | ≤ 0.3 × VDD ≈ 1.0 V | 低于此判为低 |
| 中间区 | 1.0~2.3 V | **不确定区**，会导致输入抖动与额外功耗 |

### 2. 电流能力（STM32 典型值）

| 参数 | 限制 |
| --- | --- |
| 单个 I/O 灌入/拉出电流 | **±20 mA**（绝对最大 25 mA，不建议长期跑满） |
| 单个 I/O 推荐工作电流 | ≤ 8~10 mA（保证电平满足 VOH/VOL） |
| 全部 I/O 总电流 | VDD/VSS 之和 ≤ 150 mA（详见数据手册） |
| 驱动能力 | 输出高/低在 8 mA 时仍能保证合理电平 |

**结论**：LED 一般用 2~10 mA；继电器/电机必须用三极管、MOS 或驱动芯片（ULN2003、L298N）。

### 3. 5 V 容忍（FT 引脚）

| 情况 | 说明 |
| --- | --- |
| 标 **FT**（Five-volt Tolerant）的引脚 | 可接 5 V 输入（VDD = 3.3 V 时） |
| 非 FT 引脚（如 ADC 引脚、部分电源相关脚） | **不可**接 5 V，会通过保护二极管漏电甚至损坏 |
| FT 引脚做**开漏输出**可输出 5 V 逻辑电平 | 需外部上拉到 5 V |
| FT 引脚做**推挽输出** | 只能输出 3.3 V 高电平，不能驱动 5 V 器件的高电平输入（除非 VIH 足够低） |

> **查表方式**：看数据手册 Pinouts 表的 "I/O structure" 列，标 `FT` 即可 5 V 容忍，标 `TTa`/`FTf` 等有附加说明。

### 4. 输出速度（Slew Rate）配置

STM32 可为每个引脚配置输出翻转速度（F1：2/10/50 MHz；F4：Low/Medium/High/Very High）。

| 速度设置 | 用途 |
| --- | --- |
| 低速 | 普通 IO、LED、按键扫描 —— **EMI 小、功耗低** |
| 中/高速 | SPI、SDIO、高速 PWM |
| 最高速 | 高速通信接口、时钟输出 |

> **经验**：**速度按需配置，能用低速就用低速**，可显著减少电磁干扰与过冲振铃。

## 五、寄存器详解

### 1. STM32F1 系列（CRL/CRH 模式）

F1 用 **CRL（低 8 位）** 和 **CRH（高 8 位）** 配置每个引脚，**每脚占 4 位：CNF[1:0] + MODE[1:0]**。

| MODE[1:0] | 含义        | CNF[1:0]（输出时） | 含义     |
| --------- | --------- | ------------- | ------ |
| 00        | 输入模式      | 00            | 通用推挽输出 |
| 01        | 输出 10 MHz | 01            | 通用开漏输出 |
| 10        | 输出 2 MHz  | 10            | 复用推挽输出 |
| 11        | 输出 50 MHz | 11            | 复用开漏输出 |

| CNF[1:0]（输入时） | 含义 |
| --- | --- |
| 00 | 模拟输入 |
| 01 | 浮空输入（复位默认） |
| 10 | 上拉/下拉输入（由 ODR 决定上拉还是下拉） |
| 11 | 保留 |

> 注意 F1 的"上拉/下拉输入"是同一个 CNF 值，**由 ODR 位选择**：ODR=1 → 上拉，ODR=0 → 下拉。

**F1 主要寄存器**

| 寄存器 | 作用 |
| --- | --- |
| `GPIOx_CRL` | 配置 Px0~Px7 |
| `GPIOx_CRH` | 配置 Px8~Px15 |
| `GPIOx_IDR` | 输入数据（读引脚电平） |
| `GPIOx_ODR` | 输出数据（写输出电平） |
| `GPIOx_BSRR` | 位设置/复位（原子操作，高 16 位复位、低 16 位置位） |
| `GPIOx_BRR` | 位复位（只复位） |
| `GPIOx_LCKR` | 配置锁定（防止误改） |

### 2. STM32F4 系列（MODER 等四寄存器）

F4 改为**每个功能一个寄存器、每脚占 2 位**，更清晰：

| 寄存器 | 全称 | 作用 |
| --- | --- | --- |
| `GPIOx_MODER` | Mode Register | 00=输入，01=通用输出，10=复用，11=模拟 |
| `GPIOx_OTYPER` | Output Type | 0=推挽，1=开漏 |
| `GPIOx_OSPEEDR` | Output Speed | 00=低，01=中，10=高，11=非常高 |
| `GPIOx_PUPDR` | Pull-Up/Pull-Down | 00=无，01=上拉，10=下拉，11=保留 |
| `GPIOx_IDR` | Input Data | 只读输入电平 |
| `GPIOx_ODR` | Output Data | 输出电平 |
| `GPIOx_BSRR` | Bit Set/Reset | 原子置位/复位 |
| `GPIOx_LCKR` | Lock | 锁定配置 |
| `GPIOx_AFRL/AFRH` | Alternate Function Low/High | 每脚 4 位选 AF0~AF15 |

> **AF 编号**：每个引脚可选的复用功能在数据手册的 "Alternate function mapping" 表中列出（如 PA9 的 AF7 = USART1_TX）。

### 3. 通用操作：BSRR 的原子性

```c
/* 传统读-改-写：多任务/中断下可能被打断，存在竞态 */
GPIOA->ODR |= (1 << 5);      /* 置位 PA5：读 ODR → 或 → 写回，3 步 */

/* BSRR：硬件级原子操作，一步完成，推荐！ */
GPIOA->BSRR = (1 << 5);          /* 置位 PA5（低 16 位） */
GPIOA->BSRR = (1 << (5 + 16));   /* 复位 PA5（高 16 位） */
```

> **为什么重要**：中断里也操作同一端口时，读-改-写会丢失修改，BSRR 不会。

## 六、编程实例（HAL 库）

### 1. 时钟使能（第一步，最常忘）

```c
__HAL_RCC_GPIOA_CLK_ENABLE();   /* 必须！否则寄存器写不进去 */
__HAL_RCC_GPIOB_CLK_ENABLE();
__HAL_RCC_GPIOC_CLK_ENABLE();
```

### 2. 输出配置（推挽，驱动 LED）

```c
GPIO_InitTypeDef gpio = {0};
gpio.Pin   = GPIO_PIN_5;
gpio.Mode  = GPIO_MODE_OUTPUT_PP;     /* 推挽输出 */
gpio.Pull  = GPIO_NOPULL;
gpio.Speed = GPIO_SPEED_FREQ_LOW;     /* 低速足够，减少 EMI */
HAL_GPIO_Init(GPIOA, &gpio);

HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);    /* 输出高 */
HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET);  /* 输出低 */
HAL_GPIO_TogglePin(GPIOA, GPIO_PIN_5);                 /* 翻转 */
```

### 3. 输入配置（上拉，读按键）

```c
GPIO_InitTypeDef gpio = {0};
gpio.Pin  = GPIO_PIN_0;
gpio.Mode = GPIO_MODE_INPUT;
gpio.Pull = GPIO_PULLUP;              /* 内部上拉，按键另一端接 GND */
HAL_GPIO_Init(GPIOA, &gpio);

if (HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0) == GPIO_PIN_RESET) {
    /* 按下（低电平有效） */
}
```

### 4. 按键软件消抖

```c
/* 方式一：延时消抖（简单，但阻塞） */
if (HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0) == GPIO_PIN_RESET) {
    HAL_Delay(20);                                       /* 等抖动过去 */
    if (HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0) == GPIO_PIN_RESET) {
        /* 确认按下 */
        while (HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0) == GPIO_PIN_RESET); /* 等松开 */
    }
}

/* 方式二：状态机消抖（非阻塞，推荐用于多按键） */
typedef struct {
    uint8_t  stable;      /* 稳定电平 */
    uint8_t  last;        /* 上次采样 */
    uint8_t  count;       /* 连续相同次数 */
    uint8_t  pressed;     /* 已确认按下标志 */
} key_t;

void key_scan(key_t *k, uint8_t raw)
{
    if (raw == k->last) {
        if (k->count < 5) k->count++;          /* 连续 5 次相同（如 10 ms） */
        if (k->count == 5 && k->stable != raw) {
            k->stable = raw;                   /* 更新稳定值 */
            if (raw == 0) k->pressed = 1;      /* 下降沿 = 按下 */
        }
    } else {
        k->count = 0;
        k->last  = raw;
    }
}
```

### 5. 中断方式读按键（EXTI）

```c
/* 配置下降沿触发外部中断 */
GPIO_InitTypeDef gpio = {0};
gpio.Pin  = GPIO_PIN_0;
gpio.Mode = GPIO_MODE_IT_FALLING;     /* 下降沿中断 */
gpio.Pull = GPIO_PULLUP;
HAL_GPIO_Init(GPIOA, &gpio);

/* 设置 NVIC 优先级并使能 */
HAL_NVIC_SetPriority(EXTI0_IRQn, 5, 0);
HAL_NVIC_EnableIRQ(EXTI0_IRQn);

/* 中断服务函数：EXTI0 对应 PA0/PB0/PC0 共用（需在 AFIO 中选择端口） */
void EXTI0_IRQHandler(void)
{
    if (__HAL_GPIO_EXTI_GET_IT(GPIO_PIN_0) != RESET) {
        __HAL_GPIO_EXTI_CLEAR_IT(GPIO_PIN_0);   /* 必须清标志！ */
        /* 只做置标志等短操作，耗时逻辑放主循环 */
    }
}
```

> **F1 的坑**：EXTI0 可由 PA0/PB0/PC0… 触发，但同一时刻只能选一个端口，需配置 `AFIO->EXTICR`；且使用 EXTI/复用功能时**必须使能 AFIO 时钟**（`__HAL_RCC_AFIO_CLK_ENABLE()`）。

## 七、典型应用电路

### 1. 驱动 LED

```
① 灌电流（推荐：MCU 吸电流，驱动能力强）
    3.3V ──[ R ]── LED ──→ PA5
    R = (3.3 − 2.0) / 5mA ≈ 260 Ω → 取 220~330 Ω
    输出低电平点亮

② 拉电流
    PA5 ──[ R ]── LED ──→ GND
    输出高电平点亮（驱动能力略弱）
```

### 2. 读按键

```
① 上拉 ＋ 接地按键（推荐）
    3.3V ──[ 10k ]──┬── PA0
                    │
                  [按键]
                    │
                   GND
    未按 = 高，按下 = 低  → 用 GPIO_PULLUP 可省外部电阻

② 下拉 ＋ 接电源按键
    PA0 ──[ 10k ]── GND
    PA0 ──[按键]── 3.3V
    未按 = 低，按下 = 高  → 用 GPIO_PULLDOWN
```

### 3. 驱动继电器 / 蜂鸣器（大电流负载）

```
    PA0 ──[1k]── 基极  NPN(8050)
                    集电极 ── 继电器线圈 ── 5V/12V
                    发射极 ── GND
    线圈两端并联续流二极管（1N4148/1N4007，方向反向）
    → 吸收断电瞬间的反向电动势，保护三极管
```

> **为什么不能直连**：继电器线圈电流常 30~100 mA，远超 GPIO 的 20 mA 上限，会拉低电平甚至烧脚。

### 4. 电平转换（3.3 V ↔ 5 V）

| 方向 | 方案 |
| --- | --- |
| 5 V → 3.3 V 输入 | 电阻分压（10 k + 20 k）或专用电平转换芯片（TXS0108） |
| 3.3 V → 5 V 输出 | **开漏 + 上拉到 5 V**（需外部 4.7 k 上拉）；或用三极管/专用芯片 |
| 双向 | 专用芯片，或用 MOS 管 + 上拉（I²C 常用） |
| FT 引脚接 5 V 输入 | 可直接接（查数据手册确认 FT 标记） |

### 5. I²C 的开漏必要性

```
  3.3V
   │
 [4.7k]      [4.7k]
   │            │
  SCL          SDA
   │            │
  多个设备的开漏引脚并联（线与）
```

- **为什么必须开漏**：多设备共享总线，任何设备都能拉低，但没人能"强推"高电平，避免冲突短路。
- 上拉电阻：标准模式 4.7 kΩ，快速模式 2.2 kΩ，高速模式更小。

## 八、常见问题与排查

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 引脚完全无输出 | **忘记使能 GPIO 时钟** | 加 `__HAL_RCC_GPIOx_CLK_ENABLE()` |
| 外设引脚无信号 | 配成了普通输出而非**复用模式** | 改为 `GPIO_MODE_AF_PP` 并设正确 AF 编号 |
| 输出电平不对（只有 1 V） | 负载电流过大 / 引脚被外部拉死 | 量负载电流、加驱动级 |
| 输入读数随机跳变 | 引脚**浮空**（无上下拉，外部也悬空） | 开内部上/下拉，或外部加电阻 |
| 输入始终为固定值 | 上下拉方向与外部电路相反 | 按键接 GND 用上拉；接 VDD 用下拉 |
| 按键一次触发多次 | **抖动**未消抖 | 加 20 ms 延时或状态机，或并 100 nF |
| 功耗比预期大很多 | 悬空引脚处于**不确定区**，输入级振荡 | 未用引脚配**模拟输入**或输出固定电平 |
| 干扰严重 / 过冲振铃 | 输出速度配置过高、走线长 | 降速到 Low，串 22~33 Ω 电阻 |
| 接了 5 V 后芯片发热 | 非 FT 引脚接 5 V，保护二极管长期导通 | 查 FT 标记，加分压或电平转换 |
| 中断反复触发 | **忘记清中断标志** | 在 ISR 中清标志 |
| 下载后无法再连 SWD | 把 PA13/PA14 复用为普通 IO | BOOT0=1 进系统存储器擦除 |
| 多任务下电平被"吃掉" | 读-改-写竞态 | 改用 `BSRR` 原子操作 |
| 引脚电平无法改变 | 配置被 `LCKR` 锁定 | 复位芯片或按解锁序列操作 |

### 调试技巧

- **万用表**量稳态电平（高低是否正常）。
- **示波器/logic analyzer** 看波形、边沿、抖动、频率。
- **先裸点灯**：验证最小系统 + 时钟 + GPIO 通路，再叠加复杂逻辑。
- **量电流**：判断是空载输出还是被负载拉死。

## 十、小结

- GPIO 是 MCU 与外部世界的**数字接口**，内部由**保护二极管 + 推挽 MOS 输出 + 施密特输入 + 上下拉 + 配置寄存器**构成。
- 八种模式记住两条主线：**输入要选上下拉（避免浮空）**、**输出要选推挽还是开漏**；**外设引脚必须配复用模式**。
- 编程铁律三条：**先使能时钟 → 再配模式 → 用 BSRR 做原子操作**。
- 电气铁律三条：**单脚 ≤ 20 mA（推荐 ≤ 10 mA）**、**非 FT 引脚不可接 5 V**、**输出速度按需降低**。
- 开漏的灵魂用途：**I²C 总线、电平转换、线与共享**。
- 悬空引脚是隐藏的功耗与稳定性杀手：**未用脚配模拟输入或固定输出**。
